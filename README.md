# Spicy Ramen Recipe 🍜

A simple recipe page for spicy ramen with smoked meat, built from scratch — no starter template used.

## About

This is my first HTML project where I wrote all the code independently, without following step-by-step instructions. It was built as part of freeCodeCamp's Responsive Web Design curriculum.

## What I learned

- Structuring a page with `h1`, `h2`, and `p`
- Unordered lists (`ul`) for ingredients and ordered lists (`ol`) for instructions
- Text emphasis with `em`
- Adding and sizing images with `img`, `src`, `alt`, and inline `style`
- Debugging HTML test errors and fixing tag nesting

- HTML5
